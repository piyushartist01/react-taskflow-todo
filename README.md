# TaskFlow Pro — Smart React To-Do List

A clean, editorial productivity task management application built with **React 18** and **Vite**, designed for calm, lag-free daily planning.

---

## ✨ Features

- **Calm Light Design**: Warm paper surfaces, Inter & JetBrains Mono typography, subtle shadows, and zero visual clutter.
- **Task Creation & Metadata**: Task title, Priority (High, Medium, Low), Category (Work, Personal, Study, Fitness, Creative), and Due Date picker.
- **Interactive Checkboxes**: Smooth check transitions, strike-through animation, and overdue date alerts.
- **Inline Editing**: Double-click any task title to edit in place with keyboard shortcuts (`Enter` to save, `Escape` to cancel).
- **Search & Filter**: Real-time search query matching and segmented tabs (*All*, *Active*, *Completed*) alongside category filtering.
- **Velocity Statistics Dashboard**: Real-time counters for Total tasks, In Progress, Completed, Overdue counter, and animated progress velocity bar.
- **Local Persistence**: Automatic synchronization to browser `localStorage`.
- **Bulk Actions**: Single-click "Mark all complete" and "Clear completed".
- **Responsive Layout**: Fully adaptive across mobile phones, tablets, and widescreen desktop displays.

---

## 🛠️ Tech Stack

- **React 18**
- **Vite**
- **Vanilla CSS** (Paper design tokens, custom components, responsive grids)
- **Fonts**: Inter & JetBrains Mono

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/piyushartist01/react-taskflow-todo.git

# Navigate into the project folder
cd react-taskflow-todo

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3003](http://localhost:3003) in your browser.

---

## 📦 Build for Production

```bash
npm run build
```

The production assets will be built into the `dist/` folder.
